Put your hamper photos here, one folder per box (folder name = box "id" in hampers.json):

  photos/kraft/box.jpg      empty box
  photos/kraft/1.jpg        box with item 1
  photos/kraft/1-2.jpg      box with items 1 and 2
  photos/kraft/2-4.jpg      box with items 2 and 4
  photos/kraft/1-2-3-4.jpg  box with all four

Shoot every photo from the same spot, same light, square-ish framing.
Then run:  python3 tools/hamper/build.py public_html
